# 실습용 Claude 스킬

## design-check

Figma 프레임이 AI가 그대로 구현할 수 있는 구조인지 20점 만점으로 채점하는 스킬입니다. 레이어 이름, 오토레이아웃, 변수와 스타일, 컴포넌트 네 항목을 5점씩 보고, 걸린 곳과 Figma에서 고치는 법을 알려 줍니다.

- 특징: 감점 기준을 한 줄씩 적어 고치기 쉽게 했고, 한글 글꼴과 따로 그린 버튼 같은 실습 내용을 기준에 넣었습니다. Figma 도구 이름은 Claude 데스크톱 앱의 Figma 커넥터 이름에 맞췄습니다.
- 설치: Part 7 실습(P7-3)에서 Claude가 이 폴더를 내 작업 폴더의 `.claude/skills/design-check/`로 옮깁니다.
- 쓰는 법: `design-check 스킬로 이 프레임을 채점해줘: {프레임 링크}`
- 주석: 걸린 곳을 Figma에서 바로 보려면 `design-check 스킬로 이 프레임을 채점하고, 걸린 곳은 Figma에 주석으로 남겨줘: {프레임 링크}`라고 합니다. 걸린 레이어마다 이유와 고치는 법, 프레임에는 점수 요약이 `design-check` 분류(빨강)로 달립니다. 디자인은 바꾸지 않고, 다시 채점하면 이 분류의 주석만 새로 바뀝니다. 편집 권한이 있는 파일에만 달 수 있습니다.

## 우리 팀 기준으로 고쳐 쓰기

스킬은 글로 적은 작업 절차라서 디자이너도 직접 고칠 수 있습니다. `SKILL.md`를 메모장(Mac은 텍스트 편집기)이나 VS Code로 열어 고쳐도 되고, Claude에게 말로 고쳐 달라고 해도 됩니다.

| 고치는 곳 | 예시 요청 |
|---|---|
| 4. 우리 팀 기준에 규칙 더하기(몇 줄이든) | `design-check의 우리 팀 기준에 "아이콘은 24px 프레임 안에 둔다", "누르는 곳은 높이 44px 이상으로 만든다"를 더해줘` |
| 배점 바꾸기 | `컴포넌트 항목을 10점으로 올리고 합계를 25점으로 바꿔줘` |
| 결과 모양 바꾸기 | `결과를 Slack에 붙이기 좋게 점수 한 줄과 고칠 것 세 줄로 바꿔줘` |

맨 위 `description` 한 줄은 Claude가 이 스킬을 언제 쓸지 고르는 기준입니다. 우리 팀이 쓰는 말(예: 핸드오프 전 점검)을 넣어 두면 그렇게 말할 때도 이 스킬을 고르기 쉬워집니다. 기준은 확인할 수 있는 말로 씁니다. 애매하게 쓰면 채점하는 Claude도 판단이 갈립니다.

고친 뒤에는 같은 프레임을 다시 채점해서 바라던 대로 바뀌었는지 확인합니다. 팀에 나눌 때는 `design-check` 폴더를 통째로 전달합니다. MIT License라 고쳐 쓰고 나눠도 되지만, 폴더 안의 `LICENSE`는 지우지 않습니다.
