# Part 11. 커스텀 스킬 제작과 마무리

## P11-1 | 채점 스킬을 우리 팀 기준으로 고치기

**과제**: design-check 스킬의 "4. 우리 팀 기준"에 우리 팀 규칙을 더하고, 내 상세 화면을 다시 채점해 본다. 두 줄일 필요 없이 팀 규칙에 맞춰 원하는 만큼 더한다. 막히면 아래 참고 프롬프트를 쓴다.

```
`.claude/skills/design-check/SKILL.md`의 "4. 우리 팀 기준"에 아래 규칙을 더해줘. 규칙마다 감점할 항목(A~D)도 정해줘.

- 화살표 같은 아이콘은 글자로 쓰지 않고 아이콘 컴포넌트로 만든다
- 직접 만든 컴포넌트에는 설명을 적는다
- {우리 팀 규칙. 필요한 만큼 줄을 더한다}

고친 부분만 보여줘.
```

```
design-check 스킬로 내 상세 화면을 다시 채점해줘. 우리 팀 기준에 걸린 곳은 따로 알려줘: {상세 프레임 링크}
```

`{우리 팀 규칙…}` 줄에는 팀에서 늘 지적하는 것을 원하는 만큼 적는다. 규칙은 확인할 수 있는 말로 쓴다(예: "누르는 곳(버튼, 칩, 아이콘 버튼)은 높이 44px 이상으로 만든다", "글자와 배경의 명도 대비는 4.5:1 이상으로 한다"). 우리 팀 규칙이 없으면 그 줄을 지우고 예시 두 줄만 보낸다. 배점이나 결과 모양을 바꾸는 방법은 실습 저장소 `skills/README.md`에 있다.
