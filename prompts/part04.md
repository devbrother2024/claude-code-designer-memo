# Part 4. AI 하네스와 MCP 동작 원리

## P4-1 | Figma 연결 확인

**사전 단계**: Claude 설정 → 커넥터에서 Figma를 연결한다. 연결할 때 브라우저에서 **단군소프트 교육용 계정**으로 로그인하고 허용한다. Figma 공식 스킬도 커넥터가 함께 내주므로 따로 설치하지 않는다. 그다음 입력한다.

```
Figma MCP의 whoami 도구로 내 계정을 확인해줘.
이메일, 플랜 이름, tier, seat 종류만 알려줘.
```

**확인 포인트**: 이메일이 교육용 계정이고, tier가 starter가 아니고, seat가 `Full`이면 된다. 하나라도 다르면 손을 든다.
