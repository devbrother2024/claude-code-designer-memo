## P8-2 | 디자인 토큰과 글꼴 연결

P8-1에 이어 같은 대화에서 바로 입력한다.

```
CLAUDE.md의 디자인 토큰과 Noto Sans KR 글꼴을 코드에서 같은 이름으로 쓸 수 있게 연결해줘.
CLAUDE.md에도 "코드에서는 디자인 토큰 이름만 쓴다"는 규칙을 한 줄 더해줘.
```

**확인 포인트**: 글꼴이나 색을 바꿨는데 화면이 그대로면 "개발 서버를 다시 켜줘"라고 한다. 시작 시안 변수에는 코드 이름(`var(--text-primary)` 등)이 붙어 있어 Figma가 만드는 코드도 같은 이름을 쓴다.

## P8-3 | 과제 ① 홈 화면 구현

**과제**: Figma MCP로 내 홈 프레임(`Mobile/Home`)을 메모 앱 홈 화면으로 직접 구현해 본다. 요청은 내 말로 쓰고 프레임 링크만 붙이면 된다. 계획 모드로 시작하면 무엇을 만들지 먼저 보여 준다. 막히면 아래 참고 프롬프트를 쓴다.

```
이 Figma 프레임을 메모 앱 홈 화면으로 만들어줘: {홈 프레임 링크}
```

**확인 포인트**: 브라우저 화면을 시안과 나란히 놓고 본다. 다른 곳이 보이면 캡처를 붙여 "시안과 맞춰줘"라고 한다. 한글 줄바꿈이 시안과 다른 건 규칙대로 단어 단위로 바꿔서라 괜찮다. 휴대폰 화면은 개발자 도구 기기 모드로 본다(F12 → Ctrl+Shift+M → 위쪽에서 기기 고르기. Mac은 Cmd+Option+I → Cmd+Shift+M). 실제 휴대폰에서 여는 건 Part 10 배포 뒤다.

## P8-4 | 과제 ② 상세 화면과 페이지 이동

**과제**: Figma MCP로 상세 프레임(`Mobile/Detail`, 직접 안 만들었으면 `완성 예시/Detail`)을 상세 화면으로 구현하고, 홈과 오가게 만든다(메모를 누르면 상세, 뒤로가기를 누르면 홈). 막히면 아래 참고 프롬프트를 쓴다.

```
이 Figma 프레임을 메모 상세 화면으로 만들어줘: {상세 프레임 링크}
홈에서 메모를 누르면 이 화면으로, 뒤로가기를 누르면 홈으로 가게 해줘.
```

## P8-5 | 과제 ③ 작성 화면

**과제**: Figma MCP로 작성 프레임(`완성 예시/Write`)을 작성 화면으로 구현하고, 홈의 새 메모 쓰기 버튼을 누르면 열리게 한다. 저장하기를 누르면 이 브라우저 안(로컬 스토리지)에 저장해 홈 목록에 보이게 한다. Part 9에서 Supabase로 옮긴다. 막히면 아래 참고 프롬프트를 쓴다.

```
이 Figma 프레임을 메모 작성 화면으로 만들어줘: {작성 프레임 링크}
홈의 "새 메모 쓰기" 버튼을 누르면 이 화면이 열리게 하고,
저장하기를 누르면 이 브라우저(로컬 스토리지)에 저장해서 홈 목록에 보이게 해줘.
```

**로컬 스토리지**: 브라우저가 사이트마다 내주는 작은 저장 공간이다. 새로고침해도 남지만 이 브라우저에서만 보이고(다른 브라우저·시크릿 창·휴대폰에서는 안 보임), 사이트 데이터를 지우면 사라진다. 개발자 도구(F12, Mac은 Cmd+Option+I) → Application → Local storage에서 저장된 메모를 볼 수 있다. 어느 기기에서나 보이게 하는 것은 Part 9의 Supabase다.
