# Part 8. 시안 구현

## P8-1 | Next.js 프로젝트 만들기

**폴더**: Part 6에서 연 작업 폴더(`CLAUDE.md`가 있는 곳).

```
이 폴더에 Next.js(App Router, TypeScript) + Tailwind CSS 프로젝트를 만들어줘.
- 이 폴더에는 이미 `CLAUDE.md`가 있어서 create-next-app이 충돌로 멈출 수 있다. 하위 임시 폴더에 만든 뒤 파일을 이 폴더로 옮겨줘
- package.json의 이름은 memo로
- 새로 생긴 `AGENTS.md`는 그대로 두고, 기존 `CLAUDE.md` 맨 위에 `@AGENTS.md` 한 줄을 넣어줘. 새 `CLAUDE.md`가 생겼다면 그 내용도 맨 위에 합치고, 기존 내용은 그대로 둬
- 설치 중 질문은 기본값으로
- 끝나면 개발 서버를 실행하고 열어 볼 주소를 알려줘
```

## P8-2 | Figma 변수를 코드로 옮기기

```
`CLAUDE.md`의 디자인 토큰을 CSS 변수로 만들고, Tailwind에서 같은 이름으로 쓸 수 있게 연결해줘.
- 이름은 Figma 변수 이름을 그대로 따르되 CSS에 맞게 `/`는 `-`로
- Noto Sans KR 폰트도 연결
- `CLAUDE.md`에 "코드에서는 이 CSS 변수만 쓴다"는 규칙을 한 줄 추가
```

**확인 포인트**: `globals.css`를 바꿨는데 화면이 그대로면 `.next` 폴더를 지우고 개발 서버를 다시 켠다(Turbopack 캐시). 시작 시안 변수에는 코드 이름(`var(--text-primary)` 등)이 붙어 있어 Figma가 만드는 코드도 같은 이름을 쓴다.

## P8-3 | 실습 ① 홈 화면 구현

**모드**: Plan Mode로 계획 확인 후 실행.

```
이 Figma 홈 프레임을 홈 페이지(`/`)로 구현해줘: {Mobile/Home 프레임 링크}

- 메모 카드는 `MemoCard` 컴포넌트로, 버튼은 `PrimaryButton` 컴포넌트로 분리
- 메모 데이터는 지금은 코드 안의 예시 3개로
- 시안과 최대한 똑같이, 모바일 폭 기준
- Figma의 컴포넌트 설명과 주석도 읽고 반영
- 다른 점이 있으면 이유를 알려줘
```

**확인 포인트**: 생성된 코드에서 색이 `var(--...)` 변수로 들어갔는지 찾아본다. 글자 크기는 숫자 그대로 나오고 일부 색은 hex로 샐 수 있어 스크린샷으로 대조한다.

## P8-4 | 시안과 대조하기

**첨부**: Figma 화면과 브라우저 화면의 다른 부분 캡처.

```
첨부한 캡처처럼 시안과 다른 곳이 있어. {다른 점 한 줄}. 시안에 맞게 고쳐줘.
```

**확인 포인트**: 줄바꿈이 다르면 Figma는 단어 중간에서도 줄을 바꾸고 코드는 P6-2 규칙대로 단어 단위로 바꾸기 때문이다. 카드 높이가 2px씩 크면 테두리가 크기에 들어간 것이라 "테두리는 크기에 넣지 말아줘"라고 한다(Part 5 실측). 휴대폰으로 개발 서버를 열었는데 버튼이 안 눌리면 "휴대폰 주소도 허용해줘"라고 한다(`next.config`의 `allowedDevOrigins`).

## P8-5 | 실습 ② 상세 화면 구현과 이동

```

- 이미 만든 `MemoCard`, `PrimaryButton`과 디자인 토큰 재사용
```
