**폴더**: Part 6에서 연 작업 폴더(`CLAUDE.md`가 있는 곳).

```
이 폴더에 Next.js(App Router, TypeScript) + Tailwind CSS 프로젝트를 만들어줘.

- 끝나면 개발 서버를 실행하고 열어 볼 주소를 알려줘
```

## P8-2 | Figma 변수를 코드로 옮기기

```
`CLAUDE.md`의 디자인 토큰을 CSS 변수로 만들고, Tailwind에서 같은 이름으로 쓸 수 있게 연결해줘.
- 이름은 Figma 변수 이름을 그대로 따르되 CSS에 맞게 `/`는 `-`로
- Noto Sans KR 폰트도 연결
- `CLAUDE.md`에 "코드에서는 이 CSS 변수만 쓴다"는 규칙을 한 줄 추가
```

## P8-3 | 실습 ① 홈 화면 구현

**모드**: Plan Mode로 계획 확인 후 실행.

```
이 Figma 홈 프레임을 홈 페이지(`/`)로 구현해줘: {Mobile/Home 프레임 링크}

- 메모 카드는 `MemoCard` 컴포넌트로, 버튼은 `PrimaryButton` 컴포넌트로 분리
- 메모 데이터는 지금은 코드 안의 예시 3개로
- 시안과 최대한 똑같이, 모바일 폭 기준
- 다른 점이 있으면 이유를 알려줘
```

**확인 포인트**: 생성된 코드에서 색이 `var(--...)` 변수로 들어갔는지 찾아본다.

## P8-4 | 시안과 대조하기

**첨부**: Figma 화면과 브라우저 화면의 다른 부분 캡처.

```
첨부한 캡처처럼 시안과 다른 곳이 있어. {다른 점 한 줄}. 시안에 맞게 고쳐줘.
```

## P8-5 | 실습 ② 상세 화면 구현과 이동

```
이 Figma 상세 프레임을 상세 페이지로 구현해줘: {Mobile/Detail 프레임 링크}

- 주소는 `/memo/[id]`
- 홈의 메모 카드를 누르면 해당 메모 상세로, "‹ 목록"을 누르면 홈으로
- 이미 만든 `MemoCard`, `PrimaryButton`과 디자인 토큰 재사용
```
