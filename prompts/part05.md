# Part 5. AI 친화적인 Figma 시안 설계

## P5-1 | 실습: 규칙 위반 찾아 고치기

먼저 Figma에서 `연습/규칙 위반` 프레임을 직접 보고 위반 4곳을 찾는다. 고칠 때 Claude를 쓰려면:

```
이 프레임을 AI가 구현하기 좋은 구조로 고쳐줘: {내 복제본의 연습/규칙 위반 프레임 링크}

- 간격용 빈 상자는 지우고 오토레이아웃의 padding과 gap으로
- 값으로 들어간 색은 파일의 색 변수에 연결
- 따로 그려진 버튼은 Button/Primary 컴포넌트 인스턴스로 교체
- `Frame`으로 시작하는 레이어 이름은 역할 이름으로

고친 항목을 목록으로 알려줘.
```
