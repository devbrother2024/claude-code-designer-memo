# Part 5. AI 친화적인 Figma 시안 설계

## P5-1 | 실습: 구현하면 깨질 곳 찾아 고치기

먼저 Figma에서 `연습/규칙 위반` 프레임을 보고 개발자가 AI로 구현하면 깨질 곳(좌표와 빈 상자, 카드 위에 올려 둔 글자, 값으로 넣은 색, 손으로 그린 버튼, 자동 이름)을 찾는다. 고칠 때 Claude를 쓰려면:

```
이 프레임을 개발자가 AI로 구현해도 깨지지 않게 고쳐줘: {내 복제본의 연습/규칙 위반 프레임 링크}

- 좌표로 놓인 요소와 간격용 빈 상자는 오토레이아웃의 padding과 gap으로
- 카드 위에 올려 둔 제목은 카드 안으로, 카드와 버튼은 파일의 컴포넌트로
- 값으로 들어간 색과 글자는 파일의 변수와 텍스트 스타일로
- `Frame`, `Group`으로 시작하는 이름은 역할 이름으로

고친 항목을 목록으로 알려줘.
```
