# Part 6. 디자인 토큰 규칙화

## P6-1 | 디자인 토큰을 CLAUDE.md로

**사전 단계**: Part 8에서 쓸 작업 폴더(예: `C:\work\memo`)를 Code 탭에서 연다. 아직 프로젝트 파일은 없어도 된다.

```
이 Figma 파일의 변수와 텍스트 스타일을 읽어서 이 폴더의 `CLAUDE.md`에 디자인 토큰 규칙으로 정리해줘: {내 복제본 파일 링크}

- 색, 간격, 모서리, 텍스트 스타일을 각각 표로
- 이름은 Figma 변수 이름 그대로
- 30줄을 넘지 않게
```

## P6-2 | 규칙 3줄 붙이기

강사가 주는 3줄을 `CLAUDE.md` 맨 아래에 붙여 넣는다(직접 붙여도 되고 Claude에게 시켜도 된다).

```
## 디자인 규칙
- 위 디자인 토큰에 없는 색·간격·모서리 값은 쓰지 않는다. 새 값이 필요하면 먼저 물어본다.
- 같은 모양의 UI는 기존 컴포넌트를 재사용한다.
- 한글 텍스트는 Noto Sans KR을 쓴다.
```
