# Part 6. 디자인 토큰 규칙화

## P6-1 | 디자인 토큰을 CLAUDE.md로

**사전 단계**: Part 1부터 쓰는 바탕화면의 `memo` 폴더 그대로다. 새 대화를 열었다면 입력창 아래 폴더가 memo인지 확인한다. `{내 복제본 파일 링크}`는 내 복제본 파일을 연 상태에서 오른쪽 위 **공유하기** → 창 오른쪽 위 **링크 복사**로 복사한다. 레이어 우클릭으로 복사하는 프레임 링크가 아니라 파일 전체 링크다.

```
이 Figma 파일의 변수와 텍스트 스타일을 읽고 `CLAUDE.md`에 디자인 토큰 규칙을 정리해줘: {내 복제본 파일 링크}

- 색, 간격, 모서리, 텍스트 스타일을 각각 표로
- 이름은 Figma 변수 이름 그대로
- 설명 문장 없이 표만 짧게
```

## P6-2 | 규칙 3줄 붙이기

```
## 디자인 규칙

- 같은 모양의 UI는 기존 컴포넌트를 재사용한다.
- 한글은 Noto Sans KR로 쓰고, 단어 중간에서 줄을 바꾸지 않는다.
```
