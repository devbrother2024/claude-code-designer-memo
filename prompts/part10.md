# Part 10. 배포

## P10-1 | 홈 화면 앱 준비, PWA

```
휴대폰 홈 화면에 추가하면 앱처럼 열리게 앱 이름 '메모'와 아이콘을 넣어 PWA 설정을 해줘.
```

**확인 포인트**: 홈 화면 추가는 배포한 HTTPS 주소에서 확인한다(P10-3 뒤). 아이폰(iOS 26 이상)은 설정 없이도 앱처럼 열리고, 갤럭시(안드로이드)는 이 설정(manifest)이 있어야 앱으로 설치된다.

## P10-2 | GitHub 저장소 만들고 올리기

**사전 단계**: Part 1에서 GitHub CLI 설치와 `gh auth login`을 마쳤는지 확인한다(`gh auth status`).

```
memo라는 이름으로 GitHub에 public 저장소를 만들고, 이 프로젝트를 main 브랜치로 올려줘.
올리기 전에 배포해도 오류가 없는지 확인하고, 키가 든 .env.local은 올리지 마.
```

**확인 포인트**: GitHub 화면에서 `.env.local`이 없는지 눈으로 본다. 같은 이름의 저장소가 있으면 memo-2처럼 다른 이름으로 바꿔 달라고 한다.
