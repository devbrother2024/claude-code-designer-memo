# Part 7. Figma 시안 생성과 자동 검수

## P7-1 | 홈 화면 시안 만들기

```
Figma 공식 스킬 figma-use와 figma-generate-design을 먼저 읽고, 그 절차대로 이 Figma 파일에 메모 앱 모바일 홈 화면을 새 프레임으로 만들어줘: {내 복제본 파일 링크}

- 라이브러리는 검색하지 말고 이 파일에 있는 컴포넌트·변수·텍스트 스타일만 써줘
- 프레임 이름 `Mobile/Home`, 390×844, 세로 오토레이아웃
- 위쪽: 날짜 "10월 30일 금요일", 큰 제목 "오늘까지 메모를 128개 남겼어요"(두 줄, "128개"만 포인트 색), 그 아래 분류 칩(전체·업무·개인·아이디어, 전체가 선택됨)
- 가운데: 흰 카드 두 개. "고정한 메모" 카드에 메모 2줄, "최근 메모" 카드에 메모 3줄과 오른쪽 위 "전체 보기"
- 아래쪽: + 아이콘이 붙은 "새 메모 쓰기" 버튼
- 칩, 카드 머리글, 메모 줄, 버튼은 파일의 컴포넌트 인스턴스로
- 색·간격은 파일의 변수에 연결하고, 텍스트는 파일의 텍스트 스타일 사용
- 한글 폰트는 Noto Sans KR
- 레이어 이름은 개발자가 바로 알아볼 수 있게

다 만들면 스크린샷으로 확인하고, 한글이 제대로 보이는지 알려줘.
```

## P7-2 | 상세 화면 시안 만들기

P7-1에 이어 같은 대화에서 모두 입력한다. 늦어지면 시작 시안의 `완성 예시/Detail`로 P7-4에 넘어간다.

```
같은 파일의 `Mobile/Home` 오른쪽에 상세 화면 `Mobile/Detail`(390×844)을 만들어줘.

- 위쪽: 뒤로가기, 오른쪽에 고정·공유·더보기 아이콘 버튼
- 가운데: 흰 카드 안에 분류 배지와 날짜, 제목, 구분선, 긴 본문(대제목·소제목·목록·굵은 글씨를 섞어서)
- 아래쪽: "수정하기" 버튼
- 홈과 같은 컴포넌트, 변수, 텍스트 스타일, 폰트 사용
```

## P7-3 | 채점 스킬 설치

```
https://github.com/devbrother2024/claude-code-designer-memo 저장소의 `skills/design-check` 폴더를
이 폴더의 `.claude/skills/design-check/`에 설치해줘.
설치 후 스킬 이름과 하는 일을 한 줄로 알려줘.
```

설치한 뒤에는 새 대화를 열고(폴더가 memo인지 확인) P7-4를 입력한다. 설치한 대화에서는 스킬 목록이 아직 바뀌지 않는다.

## P7-4 | 채점하기

```
design-check 스킬로 아래 두 프레임을 각각 채점해서 점수와 깎인 이유를 보여줘.
- 홈: {Mobile/Home 프레임 링크}
- 상세: {Mobile/Detail 프레임 링크}
```

## P7-5 | 깎인 곳 고치고 다시 채점

깎인 곳이 없으면 건너뛴다.

```
지적된 항목을 고쳐줘. 디자인 토큰에 없는 값은 새 변수를 만들어 연결하고, 컴포넌트 이름은 영문으로 바꿔줘.
다 고치면 design-check 스킬로 두 프레임을 다시 채점해서 점수가 어떻게 바뀌었는지 표로 보여줘.
```
