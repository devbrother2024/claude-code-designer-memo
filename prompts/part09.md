# Part 9. Supabase 데이터 연동

Supabase 연결부터 앱 저장까지는 강사와 함께 따라 한다(과제 아님). 프롬프트를 처음부터 그대로 붙여 넣는다.

## P9-1 | Supabase 연결과 확인

**사전 단계**: supabase.com에 가입하고 New project로 새 프로젝트를 만든다(이름 memo, 지역 Northeast Asia (Seoul)). 데이터베이스 비밀번호는 Generate a password로 자동 생성하고 따로 적어 두지 않아도 된다(오늘은 쓰지 않는다). Security 칸(Enable Data API 켜짐, Automatically expose new tables 켜짐, Enable automatic RLS 꺼짐)은 그대로 둔다. Claude 왼쪽 메뉴의 사용자 지정 → 커넥터에서 Supabase를 찾아 Claude에 연결을 누르고, Supabase 승인 화면에서 조직을 골라 Authorize Claude를 누른 뒤, Code 탭에서 새 대화를 연다.

```
Supabase 연결이 잘 됐는지 확인하고, 내 프로젝트 목록을 보여줘.
```

## P9-2 | 계획 모드로 한 번에 옮기기

**사전 단계(키 넣기)**: Supabase 화면 위쪽 **Connect** → Framework → Next.js(App Router) → `.env.local` 탭의 두 줄(`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`)을 복사해 memo 폴더(package.json이 있는 곳)에 `.env.local` 파일로 저장한다. 메모장은 파일 형식을 "모든 파일"로 바꿔야 `.txt`가 붙지 않는다. Part 2에서 `.env` 같은 키 파일은 Claude가 못 읽게 막아 두었으니 키는 직접 넣고, 값을 대화에 붙이지 않는다. `sb_secret_`로 시작하는 키는 쓰지 않는다.

입력창 아래 모드를 **계획**으로 바꾸고 입력한다. Claude가 계획을 보여 주면 읽고 승인한다.

```
지금 메모 앱은 메모를 코드 안의 예시와 이 브라우저(로컬 스토리지)에만 저장하고 있어.
이걸 Supabase로 옮겨서 어느 기기에서 열어도 같은 메모가 보이게 하고 싶어.
고치기 전에 계획부터 보여줘. 계획에는 이런 내용이 있으면 좋겠어.

- Supabase의 {프로젝트 이름} 프로젝트에 메모를 담을 표(테이블) 만들기. 지금 화면에 보이는 정보(제목, 서식 있는 내용, 분류, 색, 고정, 날짜)를 모두 담을 수 있게
- 지금 앱의 예시 메모를 그 표에 옮겨 넣기. 이 브라우저에 저장해 둔 메모는 옮기지 않아도 돼
- 홈과 상세는 Supabase에서 메모를 읽고, 작성 화면에서 저장하면 Supabase에 저장되게 바꾸기. 홈 제목의 메모 수도 실제 개수로
- 접속 주소와 공개 키는 내가 .env.local에 넣어 뒀어. 이름은 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- 교육용이라 로그인 없이 누구나 읽고 쓰고 지울 수 있게

계획대로 다 하고 나면 홈에 메모가 보이고 새 메모가 저장되는지 직접 확인해줘.
```

**확인 포인트**: 계획에서 프로젝트 이름, 표에 담을 정보(제목·서식 있는 내용·분류·색·고정·날짜), `.env.local` 이름을 그대로 쓰는지 본다. 이상하면 승인 전에 말로 고친다. 끝나면 홈에 메모 5개가 보이고 제목이 "5개 남겼어요"로 바뀌며, 새 메모를 저장하면 목록에 들어간다. Supabase 화면의 Table Editor에서도 memos와 메모가 보인다. 누구나 읽고 쓰게 여는 방법은 실행마다 다를 수 있다(RLS를 끄면 표 이름 옆에 UNRESTRICTED가 붙고, RLS를 켜고 누구나 허용하는 규칙을 넣으면 붙지 않는다. 교육용으로는 둘 다 괜찮다). 배포 주소를 아는 누구나 보고 지울 수 있으니 회사·개인 정보는 넣지 않는다.

```
홈의 전체 보기를 누르면 이 화면으로 가고, 검색·분류·정렬도 동작하게 해줘.
```
