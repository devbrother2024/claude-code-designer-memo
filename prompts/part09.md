# Part 9. Supabase 데이터 연동

## P9-1 | Supabase MCP 연결과 테이블 만들기

**사전 단계**: Supabase의 MCP 연결 화면에서 내 프로젝트를 고르고 Read-only는 끄고 Client는 Claude Code를 고른다. 나온 연결 명령을 Code 탭에 붙여 "이 명령으로 Supabase MCP를 연결해줘"라고 하고, 브라우저 로그인으로 허용한다. 막히면 SQL Editor에서 저장소 `checkpoint/02-supabase` 브랜치의 `supabase/migrations` SQL을 붙여 넣고 Run한다.

**과제**: 연결한 Supabase MCP로 메모를 담을 `memos` 테이블을 만들어 달라고 내 말로 요청한다. 담을 것은 제목, 본문, 작성일이고, 지금 앱의 예시 메모 3개를 넣는다. 교육용이라 누구나 읽고 추가만 할 수 있게 한다. 테이블 이름은 체크포인트와 맞추려고 `memos`로 정한다. 막히면 아래 참고 프롬프트를 쓴다.

```
Supabase MCP로 내 프로젝트 {Supabase 프로젝트 이름}에 메모를 담을 `memos` 테이블을 만들어줘.
제목, 본문, 작성일을 담고, 지금 앱의 예시 메모 3개도 넣어줘. 교육용이라 누구나 읽고 추가만 할 수 있게 해줘.
```

## P9-2 | 홈 목록을 Supabase에서 읽기

**과제**: 홈과 상세가 코드 안의 예시 대신 Supabase의 메모를 읽게 내 말로 요청한다. 키 값은 대화에 붙이지 않고 Claude가 만든 `.env.local`에 직접 넣는다. 프로젝트 위쪽 Connect 버튼에서 Project URL과 공개 키(`sb_publishable_`로 시작)를 복사한다. `sb_secret_`로 시작하는 키는 쓰지 않는다. 막히면 아래 참고 프롬프트를 쓴다.

```
홈과 상세가 코드 안의 예시 대신 Supabase의 memos 테이블에서 메모를 읽어 오게 바꿔줘.
키는 내가 직접 붙여 넣을 테니 .env.local에 넣을 자리만 만들어줘.
```

## P9-3 | 작성 화면 만들고 저장하기

**과제**: "새 메모" 버튼을 누르면 메모를 쓰는 화면이 나오고, 저장하면 홈 목록에 보이게 내 말로 요청한다. Figma에 없는 화면이라 홈·상세와 같은 디자인으로 만들게 한다. 막히면 아래 참고 프롬프트를 쓴다.

```
"새 메모" 버튼을 누르면 메모를 쓰는 화면이 나오게 해줘. 제목과 본문을 쓰고 저장하면 Supabase에 저장되고 홈 목록에 보이게.
Figma에는 없는 화면이니 홈·상세와 같은 디자인으로 만들어줘.
```
