# Part 9. Supabase 데이터 연동

Supabase 연결부터 앱 저장까지는 강사와 함께 따라 한다(과제 아님). 프롬프트를 처음부터 그대로 붙여 넣는다.

## P9-1 | Supabase 연결과 확인

**사전 단계**: supabase.com에 가입하고 New project로 새 프로젝트를 만든다(이름 memo, 지역 Northeast Asia (Seoul)). 데이터베이스 비밀번호는 Generate a password로 자동 생성하고 따로 적어 두지 않아도 된다(오늘은 쓰지 않는다). Security 칸(Enable Data API 켜짐, Automatically expose new tables 켜짐, Enable automatic RLS 꺼짐)은 그대로 둔다. Claude 왼쪽 메뉴의 사용자 지정 → 커넥터에서 Supabase를 찾아 Claude에 연결을 누르고, Supabase 승인 화면에서 조직을 골라 Authorize Claude를 누른 뒤, Code 탭에서 새 대화를 연다.

```
Supabase 연결이 잘 됐는지 확인하고, 내 프로젝트 목록을 보여줘.
```

## P9-2 | 메모 테이블 만들고 메모 넣기

```
Supabase의 {프로젝트 이름} 프로젝트에 memos 테이블을 만들어줘.
지금 앱 화면에 필요한 칸을 모두 담고, 지금 앱의 예시 메모도 모두 넣어줘.
교육용이라 누구나 읽고 쓰고 지울 수 있게 RLS는 꺼줘.
```

**확인 포인트**: Supabase 화면의 Table Editor에서 memos와 메모 5개를 본다. 테이블 이름 옆 UNRESTRICTED 표시는 RLS를 끈 표시라 교육용으로는 괜찮다. 배포 주소를 아는 누구나 보고 지울 수 있으니 회사·개인 정보는 넣지 않는다.

## P9-3 | 앱이 Supabase에서 읽게 하기

**사전 단계**: 프로젝트 위쪽 Connect 버튼에서 Project URL과 공개 키(`sb_publishable_`로 시작)를 복사해 둔다. `sb_secret_`로 시작하는 키는 쓰지 않는다.

```
앱이 Supabase의 memos 테이블에서 메모를 읽어 오게 바꿔줘. 홈과 상세 둘 다.
키는 내가 .env.local에 직접 붙여 넣을 테니 넣을 자리만 만들어줘.
```

**확인 포인트**: Claude가 만든 `.env.local`에 값만 붙여 넣고 "개발 서버 다시 켜줘"라고 한다. 홈에 메모 5개가 보이고 제목이 "5개 남겼어요"로 바뀌면 성공이다.

## P9-4 | 작성 화면에서 저장하기

```
작성 화면에서 저장하기를 누르면 Supabase memos 테이블에 넣고, 홈으로 돌아가 목록에 보이게 해줘.
```
