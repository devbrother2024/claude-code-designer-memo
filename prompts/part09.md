# Part 9. Supabase 데이터 연동

Supabase 연결부터 앱 저장까지는 강사와 함께 따라 한다(과제 아님). 프롬프트를 처음부터 그대로 붙여 넣는다.

## P9-1 | Supabase 연결과 확인

**사전 단계**: supabase.com에 가입하고 새 프로젝트를 만든다(지역 Northeast Asia (Seoul)). 데이터베이스 비밀번호는 Generate a password로 자동 생성하고 따로 적어 두지 않아도 된다(오늘은 쓰지 않는다). Claude 설정 → 커넥터에서 Supabase를 연결하고(Supabase 로그인 → 내 조직 허용), Code 탭에서 새 대화를 연다.

```
Supabase 연결이 잘 됐는지 확인하고, 내 프로젝트 목록을 보여줘.
```

## P9-2 | 메모 테이블 만들고 메모 넣기

```
Supabase의 {프로젝트 이름} 프로젝트에 memos 테이블을 만들어줘.
제목, 본문, 작성일을 담고, 지금 앱의 예시 메모 3개도 넣어줘.
교육용이라 누구나 읽고 쓰고 지울 수 있게 RLS는 꺼줘.
```

**확인 포인트**: Supabase 화면의 Table Editor에서 memos와 메모 3개를 본다. 테이블 이름 옆 UNRESTRICTED 표시는 RLS를 끈 표시라 교육용으로는 괜찮다. 배포 주소를 아는 누구나 보고 지울 수 있으니 회사·개인 정보는 넣지 않는다.

## P9-3 | 앱이 Supabase에서 읽게 하기

**사전 단계**: 프로젝트 위쪽 Connect 버튼에서 Project URL과 공개 키(`sb_publishable_`로 시작)를 복사해 둔다. `sb_secret_`로 시작하는 키는 쓰지 않는다.

```
앱이 Supabase의 memos 테이블에서 메모를 읽어 오게 바꿔줘. 홈과 상세 둘 다.
키는 내가 .env.local에 직접 붙여 넣을 테니 넣을 자리만 만들어줘.
```

**확인 포인트**: Claude가 만든 `.env.local`에 값만 붙여 넣고 "개발 서버 다시 켜줘"라고 한다. 홈에 메모 3개가 보이면 성공이다.

## P9-4 | 작성 화면에서 저장하기

```
작성 화면에서 저장하기를 누르면 Supabase memos 테이블에 넣고, 홈으로 돌아가 목록에 보이게 해줘.
```

## 과제 시간: 기능 더하기

**과제**: 아래 세 묶음에서 두세 개를 골라 내 말로 요청한다. Figma 시안 없이 바이브 코딩으로 만든다. 분류·고정·색 라벨은 Supabase 테이블에 칸을 더해야 해서 "필요한 칸도 같이 추가해줘"를 넣는다. 막히면 아래 참고 프롬프트를 쓴다.

## P9-5 | 편집: 수정

```
상세 화면의 수정하기를 누르면 작성 화면에서 그 메모를 고칠 수 있게 해줘. 저장하면 Supabase에도 반영해줘.
```

## P9-6 | 편집: 삭제

```
상세 화면에서 메모를 지울 수 있게 해줘. 지우기 전에 한 번 더 물어보고, Supabase에서도 지워줘.
```

## P9-7 | 편집: 고정

```
중요한 메모를 고정할 수 있게 해줘. 고정한 메모는 홈 맨 위 '고정한 메모' 카드에 따로 모아 줘. Supabase 테이블에 필요한 칸도 같이 추가해줘.
```

## P9-8 | 찾기: 검색

```
홈 위쪽에 검색창을 넣어서 제목이나 본문으로 메모를 찾을 수 있게 해줘.
```

## P9-9 | 찾기: 분류

```
메모마다 업무, 개인, 아이디어 중 하나로 분류할 수 있게 해줘. 작성 화면에서 고르고, 홈에서 분류별로 걸러 볼 수 있게. Supabase 테이블에 필요한 칸도 같이 추가해줘.
```

## P9-10 | 찾기: 정렬

```
홈 목록을 최신순, 오래된순, 제목순으로 바꿔 볼 수 있게 해줘.
```

## P9-11 | 꾸미기: 색 라벨

```
메모마다 색 라벨을 고를 수 있게 해줘. 디자인 토큰의 라벨 색을 쓰고, 홈 목록의 아이콘 칸에 그 색이 보이게. Supabase 테이블에 필요한 칸도 같이 추가해줘.
```

## P9-12 | 꾸미기: 다크 모드

```
다크 모드를 만들어줘. 휴대폰 설정을 따르고, 홈 위쪽 버튼으로도 바꿀 수 있게. 색은 디자인 토큰의 다크 모드 값으로.
```
