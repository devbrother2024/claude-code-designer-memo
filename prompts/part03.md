# Part 3. 미니 실습

## P3-1 | 실습 ① 1단계: 말로만 랜딩페이지

**모드**: 기본(매번 묻기). 파일 생성 승인이 뜨면 허용한다.

```
이 폴더에 `index.html` 파일을 새로 만들어 정적 랜딩페이지를 완성해줘.

## 제품 설정
- 이름: Lumo
- 한 줄 소개: 생각보다 빠른 AI 메모 앱

## 섹션 구성
1. Hero: 제품명, 한 줄 카피, 서브 카피, CTA 버튼 1개
2. 핵심 기능 3가지: 카드 3개(이모지 아이콘, 제목, 2줄 설명)
3. 하단 CTA와 푸터(저작권 한 줄)

## CTA 버튼
- 레이블: "무료로 시작하기" (Hero와 하단 동일)

## 디자인 톤
- 라이트 톤, 포인트 컬러는 1개만 정해 일관되게
- 타이포 위주, 여백 넉넉하게

## 제약
- 파일은 `index.html` 하나로만
- 외부 라이브러리 없이 순수 HTML/CSS
- 이미지 대신 이모지와 배경색·그라디언트
- 데스크톱 기준, 모바일에서는 세로로 쌓이게

끝나면 만든 파일 경로와 섹션을 3줄로 요약해줘.
```

## P3-2 | 실습 ① 2단계: 레퍼런스 이미지로 다듬기

**첨부**: 본인이 좋아하는 랜딩페이지 캡처(Windows `Win+Shift+S`). 2분 안에 못 고르면 강사 예비본.

```
첨부한 이미지의 무드(컬러, 배경, 타이포, 버튼 느낌)로 방금 만든 `index.html`을 다시 다듬어줘.
섹션 구성과 문구는 그대로 둬.
```

## P3-3 | 실습 ② 미니 게임: Plan Mode로 스펙 입력

**모드**: Plan Mode로 바꾼 뒤 입력. 계획을 읽고 필요하면 고칠 점을 말한 다음 실행을 승인한다.

```
이모지 메모리 카드 게임을 `game.html` 한 파일로 만들고 싶어. 기존 `index.html`은 건드리지 마.

## 게임 스펙
- 보드: 4×4 (16장, 8쌍)
- 이모지: 🐶 🐱 🦊 🐻 🐼 🐵 🐯 🦁 각 2장, 매 게임 무작위 섞기
- 카드 상태: 뒷면 / 앞면 / 매칭 완료(반투명 고정, 클릭 안 됨)
- 2장이 같으면 고정, 다르면 잠시 뒤 다시 뒷면
- 상단에 타이머(첫 클릭부터, mm:ss), 시도 횟수, "다시 시작" 버튼
- 다 맞추면 가운데 완료 창(시간, 시도 횟수, "다시 하기")

## 디자인 톤
- 둥근 카드, 부드러운 그림자, 옅은 파스텔 배경
- 카드 뒷면은 옅은 그라디언트

## 제약
- `game.html` 하나에 HTML·CSS·JavaScript 모두
- 외부 라이브러리 없이
- 모바일에서도 4×4 유지, 카드 크기만 줄이기
```

## P3-4 | 실습 ② 계획 수정 (선택, 실행 승인 전)

```
최고 기록 기능도 넣자. 게임을 끝내면 시간과 시도 횟수를 최고 기록으로 저장해줘. 계획을 다시 보여줘.
```
